## Comandos Utilizados
Durante el desarrollo del trabajo práctico, se utilizaron los siguientes comandos fundamentales de Git:
* `git init` (para inicializar el repositorio de forma local)
* `git status` (para verificar el estado de los archivos y cambios realizados)
* `git add` (para registrar los archivos en el área de preparación o staging)
* `git commit -m "..."` (para guardar los cambios de forma ordenada en el historial)
* `git push origin master` (para subir los seis commits locales directamente a GitHub)
