## Descripcion del proceso

Para comenzar este proyecto, cree una carpeta especifica en mi Escritorio respetando el formato solicitado e inicialice el repositorio local con git init. Luego, organice la estructura interna del repositorio creando una carpeta adicional para los resources y genere los archivos obligatorios. Utilice comandos como git status y git add para preparar las versiones de mis documentos de texto y mi archivo PDF. Despues, registre formalmente estos avances mediante commits claros en el historial local. Finalmente, cree el repositorio publico en la plataforma Github para poder publicar mis archivos locales en internet mediante git push y documente el proceso en este archivo de entrega.

## Dificultades encontradas

Al principio tuve dificultades con la terminal al intentar navegar entre carpetas mediante el comando cd, debido a la sensibilidad del sistema Linux con respecto a las mayusculas, minusculas y espacios en los nombres de los directorios. Tambien tuve que reorganizar la estructura para cumplir estrictamente con el formato de nombre sugerido por el docente. Lo resolvi prestando mayor atencion a la sintaxis exacta, usando comillas para nombres con espacios y creando una carpeta limpia desde cero en el Escritorio con mi nombre oficial.
